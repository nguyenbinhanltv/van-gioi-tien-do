# Pháp tu B — premium semi-chibi v1

New style set; original semi-realistic assets remain untouched.

The orchestrator visually approved the corrected T1 master/turnaround before motion generation: short plum tunic and trousers, long sleeves, vermilion sash/fan, compact split pin with tassel, earrings and one fixed face. The fan stays in the anatomical left hand in all five views. `reference/anatomy-landmarks.json` records the approximate anatomy review and shared 216 px @2× crown-to-sole target, separately from alpha bounds.

`reference/T1-T5-front.raw.png` and the five `T<n>.front.master.png` images are front edit references. T1/T2 use tunic/trousers; the layered robe begins at T3. Tier FX are reference-only. Future tier/costume motion is produced by pose-preserving edits of the T1 sheets with the public variant tooling, never independent motion generation.

## E motion

15 clips / 202 frames, public `smooth-v2` profile (D46). Every source frame includes the naturally held fan. Hit (6) and dash (10) share one 4×4 sheet using the public grouped mapping. Other clips have one sheet each. The two spare cells in each 14-frame attack sheet are empty.

The original generation guides and raw attempts are retained. Whole-sheet DPI normalization is declared by `E/project.json`; the character-wide scale is fixed in `character-calibration.json`. Hit/dash use one separately measured, shared sheet calibration after layout reflow. No individual frame is fitted or rescaled. `E/templates/run.qa.template.json` records one measured ground translation preserving flight; its original generation guide is unchanged.

All soft findings and manual visual observations are explicit in `quality-backlog.json`. Dynamic run tucks are retained. D47 validates 16 reviewed output-cell skull crown/chin annotations on run/dash posture exceptions; the same cells are listed as INFO observations in the backlog. Ordinary in-band upright cells retain their normal gate. `E/quality-baseline-migration.json` preserves the two soft-value changes caused by the corrected master alpha/anchor input; both defects remain open.

`character-framing.json` applies one fixed +1 px horizontal translation to every master and motion frame. `check-canvas.ts` verifies all 202 aligned frames against an expanded diagnostic canvas: zero pixels, including partial alpha, are lost outside the 256 px cell. This is a character-wide translation without per-frame fitting. The alpha-fixed master before this translation is preserved as `reference/E.master.alpha-fixed-unframed.png` for the approved baseline migration.

The reproducible D41 export uses the new Cocos resource directory `apps/client-cocos/assets/resources/dragonbones/phap-tu-chibi-v1/`. These full frames are sources for later D45 weapon-removal edits and layered export; no weapon/body swapping is claimed yet. The orchestrator explicitly authorized publishing full-frame direction PRs before D45 tooling is ready.

## Reproduce

Run from the repository root after `npm ci`:

```sh
node tools/rig/scripts/run-ts.mjs assets-src/placeholder/phap-tu-chibi-v1/prepare-masters.ts
node tools/rig/scripts/run-ts.mjs assets-src/placeholder/phap-tu-chibi-v1/prepare-fronts.ts
node tools/rig/scripts/run-ts.mjs assets-src/placeholder/phap-tu-chibi-v1/prepare-E.ts
node tools/rig/scripts/run-ts.mjs assets-src/placeholder/phap-tu-chibi-v1/calibrate-group.ts
npm run sprite:build -w @vgtd/sprite -- --project assets-src/placeholder/phap-tu-chibi-v1/E/project.json --out apps/client-cocos/assets/resources/dragonbones/phap-tu-chibi-v1
```

`prepare-E.ts` preserves an existing locked calibration and uses the archived exact generation master when present. `calibrate-group.ts` updates the existing two clip mappings without duplicating them. Source annotations and original raw images are never regenerated by the build command. `key-exterior.ts` preserves enclosed warm face/eye highlights while removing exterior/trapped white backdrop; the original globally keyed generation input remains archived as `reference/E.master.generation-v1.png`.

For engine QA, use the shipped six-file export in its new resource directory, then run:

```sh
node apps/client-cocos/scripts/capture.mjs --src dragonbones/phap-tu-chibi-v1 --stem phaptuchibi --direction E --mode single --animations all --frames 24 --zoom 2 --sample midpoint --gif --out <capture-output>
```

Real Cocos Creator 3.8.8 capture completed successfully for all 15 E clips. The durable runtime gallery is attached to worker 25's master checkpoint. Capture outputs and build logs are working material outside Git; source/export hashes and the engine gate are recorded beside the project.
