# Kiếm tu: danh sách phần cần vẽ bù (underpaint / extension)

Ngưỡng kiểm tra: 3 px. Tên vùng `kiemtu_page` là trang atlas gộp; `slot#k` là đảo (quad) thứ k của slot.

Generated by `npm run artifacts -w @vgtd/rig` (`underpaintNeeds`). A seam opens when a bent joint reveals ground that no piece covers: the neighbouring pieces must be painted or extended under the joint by about **extend px** (rig px @1x; atlas px = 2x). Limit checked: 3 px.
