# Asset pipeline

Authoritative numbers live in docs, not here. Read them before deciding anything:
`docs/00-ho-so-tong-hop.md` section 3 (budgets, atlas, compression, icon rows) and the D1-D13 rows of `docs/DECISIONS.md`,
`docs/02-asset-matrix-2d.md` (bundles, formats, initial-load table), `docs/06-toi-uu-render.md` (RAM and initial package budgets,
memory per format), `docs/05-ui-ux-icon.md` (icons, 9-slice), `docs/04-tilemap.md`, `docs/03-nhan-vat-quai-vat.md`.
Grid, chunk, layer and direction constants come from `@vgtd/shared`; asset code must not redefine them.

## Budgets to enforce (values: see docs/00 section 3 and docs/06)

- **Web initial package: 25 MB** (the old 29/30 MB values are superseded, `docs/DECISIONS.md` D5). Everything else is a lazily
  loaded Asset Bundle. Check the breakdown table in `docs/06-toi-uu-render.md` before adding anything to Core.
- **Atlas: max 2048 x 2048 (Web/Mobile; PC map atlases may use 4096), power-of-two pages, padding 2 px + extrude.**
- Draw-call, particle, Spine-update and RAM budgets: docs/00 section 3 performance table.
- Icons: source 256, export 48 / 64 / 128, transparent background, quality border composed at runtime; 6 quality tiers.
- Light always from NW; tile 64 x 32 @1x (drawn 128 x 64 @2x).

## Compression matrix (details and rationale: docs/00 section 3 "Nén", docs/02)

| Target | Format                                                                    |
| ------ | ------------------------------------------------------------------------- |
| Web    | KTX2 (ETC1S for tiles/props/VFX, UASTC for characters/UI) + WebP fallback |
| Mobile | ASTC (4x4 / 6x6 / 8x8 by asset class)                                     |
| PC     | PNG                                                                       |

## Commands (run from `tools/procgen/` or `npm run <script> -w @vgtd/procgen` from the root)

```bash
npm run gen         # gen:tilemap + gen:items -> out/   (same seed -> same asset; commit seeds, not images)
npm run render      # compile shaders (glslangValidator) + SVG -> PNG
npm run validate    # deterministic QA gate -> out/reports/qa_raw.json (exit 0 ok / 10 warnings / 20 errors)
npm run pack        # shelf-pack atlases (padding 2 + extrude, pow2 <= 2048) -> build/atlas
npm run compress    # PC branch; for web/android/ios: node pipeline/compress_textures.js <web|android|ios|pc> <atlas> <out>
npm run smoke       # whole chain gen -> render -> validate -> pack -> validate -> compress
npm test            # vitest
```

Optional tools (`@resvg/resvg-js`, `glslangValidator`, `basisu`, `cwebp`, `astcenc`) are listed in `tools/procgen/README.md`.
Missing tools make steps report `skipped`; a skipped step is **not verified**, so say so in the PR and add it to
`docs/OPEN-ITEMS.md` instead of claiming success. KTX2/ASTC compression and the AI-driven pipeline steps are currently
unverified (see `docs/OPEN-ITEMS.md`). Generated output (`out/`, `build/`, `reports/`, `preview/`) is git-ignored.

## Mandatory license check for third-party or MCP-sourced assets

Applies to anything not generated by `tools/procgen` or drawn in-house: itch.io, OpenGameArt, Kenney, game-icons.net, fonts,
audio, AI-generated images (for example from an asset-scout or image-generation MCP), and anything pulled from a URL.

1. **Before downloading into the repo or a bundle**, find the license from the source page or the tool's license lookup
   (for example `get_itch_license`, or the Kenney / OpenGameArt / game-icons license field). Do not guess.
2. Accept only licenses that allow commercial use and redistribution inside a game binary (for example CC0, CC-BY with
   attribution, MIT/OFL for fonts). Reject or escalate: NC (non-commercial), ND, SA when it would force the game's own
   art under the same license, "personal use only", unknown or missing license, ripped/unattributed art.
3. Record each asset in `docs/ASSET-LICENSES.md` (create it if absent): name, source URL, author, license, attribution text
   required, date checked, where used. Add attribution to the in-game credits list if the license requires it.
4. Check style against the art direction (`docs/02-asset-matrix-2d.md`, light from NW, 2:1 iso, ink-wash UI) before importing.
5. Re-validate with `npm run validate` and `npm run pack` and re-check the initial-package budget (25 MB for Web).
6. If you cannot establish the license, do not add the asset; log it in `docs/OPEN-ITEMS.md` for a human decision.
